# 🐾 Pinezoo & Python – FNB App Academy (2025)

![Pinezoo Screenshot](images/screenshot.png)

This repository contains projects completed during the **Full Stack Development Course at FNB App Academy (2025)**. It includes the **Pinezoo website project** (HTML/CSS/JavaScript) and Python programming exercises, reflecting my growth in both front-end and back-end development.

---

## ✨ Pinezoo Project
The Pinezoo project was a front-end web development exercise designed to practice:
- **HTML5 structure** (headers, navigation, content sections).  
- **CSS styling** for layout and design.  
- **Navigation tabs** for Animals, Map, Places, Weather, and Feedback.  
- **Content pages** with images, descriptions, and schedules (e.g., Amphitheatre shows).  
- Responsive design principles.  

Deployment: Hosted locally during the course, with assets organized into `images/` and `styles.css`.
